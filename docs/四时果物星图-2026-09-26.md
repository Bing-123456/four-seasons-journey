# 四时果物星图更新

针对深绿放射文字图的视觉问题，重做四时页。用四季浅色背景、统一的自然果物插画、原生名称和轻连线呈现季节关系。核心组与外围组各占一页，支持横向滑动和顶部按钮切换；主页面仍固定一屏，正文在详情子页阅读。

保留48个季节水果节点、核心/外围分组、季节中心连接、所有详情入口、季节选择保存、中英文、果灵搜索和地点入口。分组沿用需求文档口径，不新增关于植物原生地的断言。
