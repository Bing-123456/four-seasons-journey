## 0.5.7 → 0.6.0 累计变化

### 修复的真实 Bug
1. **3D 课堂页崩溃（0.5.7）**：`pages/heritage/index.js` 使用了 `i18n` 但缺失 `require`，任何语言下打开该页必现 `i18n is not defined`；同时导致 5 条单测失败。已修复。
2. **7 处 WXML 嵌套绑定渲染错误（0.5.8）**：heritage / manage / route 中 `{{editing ? '{{L.xxx}}' : ...}}` 这类写在字符串引号里的嵌套绑定，WXML 不解析嵌套花括号，中文模式下按钮一直显示 `{{L.rt_edit_done}}` 字面文字。全部改为直接引用。
3. **我的页农场阶段标签不显示（0.5.9）**：页面绑定 `farm.stageLabel`（拍平字段），而 `farm.summary()` 返回嵌套 `farm.stage.label`，导致成长阶段胶囊、下一步浇水提示、农谚阶段名三处空白。已在刷新处统一拍平并按语言显示。
