# 新功能数据与真机检查

## 本机数据
昵称(identity)、伙伴(companion)、卖家(seller)与出游profile并列保存。当前存储版本保持2，做兼容性字段补全，不重建个人路线和收藏。旧v1仍执行原有虚构经营数据退役逻辑。个人/演示存储、伙伴文件目录隔离；异步导出绑定开始时分区。清除当前分区或重置演示会清理该分区预览，另一账户不受影响。

照片选择仅在页面临时变量和预览中存在，卸载清除，不上传、不进入存储、日志与分享。后端未配置图片能力时拒收。通过系统相机/相册授权不代表允许云端上传。

## 位置
app.json已声明getLocation与chooseLocation，用途为用户主动设置出发点。只有点击“使用当前位置”后说明用途并请求一次GCJ-02坐标。地图导航继续仅打开目的地。起点不发送给DeepSeek，不记入行为日志或分享参数。

发布前需在微信后台按实际用途补充《用户隐私保护指引》，核验当前AppID的接口资格与服务类目，不能只靠app.json代替后台设置。未擅自调整后台权限。

## 必須真机完成
- iOS与Android首次授权/已授权/拒绝、系统定位关闭、超过12秒、地图手动选点覆盖迟到结果。
- 相机/相册选择后欢迎不重播；系统返回、分享直达、冷启动一次欢迎及跳过。
- 伙伴绘图触点与旋转镜像一致、窄屏键盘/安全区、保存失败、文件清理。
- 开启定位后仍可清除起点；拒绝后原起点保留。

本次只有开发工具模拟器与逻辑验证，不能声称上述真机和平台资格已验收。照片授权未解决前维持本地开发引用，不发布含未授权实拍的公开商业版本。
