## 二、红山动物园「游园 Agent」赛题：5 个开源同题项目（灵犀未公开，这些是对标）

- **红山朋友**：LLM 降级链 Qwen3-Max→Qwen-Plus→模板兜底（temperature=0、8s 超时、结构化校验重试≤2）；拍照识动物 qwen-vl-plus→max；**golden_dataset + 100+ cassettes 回放 + eval-gate CI 门禁**

## 四、对「Agent 太简单」的架构回答

借鉴后的架构叙事从「单次检索增强问答」升级为**分层混合架构**：

```
交互层：语音(ASR流式/方言) + 拍照(VL) + 文字
规则层：高频问题模板秒回 + 境外话题本地拦截（现有）
检索层：本地素材库检索 + 农谚（现有）
模型层：主力模型 → 轻量模型 → 模板 三级降级链
记忆层：本地分区聊天记录 + 跨会话话题接续
导览层：点位触发 + 行程感知讲解（借鉴红山）
声景层：专用小模型识别物候声音（差异化）
评测层：检索 MRR + QA golden set + 回归门禁（答辩王牌）
```

每一层都有本次比赛项目的先例背书，且全部符合「具体人群+具体场景+可控成本」的赛事评审口味。
