# 瓜游记：开源方案调研与复用说明

核验日期：2026 年 9 月 22 日。本文对应当前微信小程序开发版，区分实际复用、设计参考和后续计划；不使用仓库星数或未核实的节省工时作为选型依据。

## 本轮农耕课堂更新

2026-09-22 后续改版中，`pages/heritage/index` 默认进入 `grain-mill` 农耕课堂：磨盘、磨棒与谷粒采用新增程序几何表达，依据河南博物院公开资料设计结构和往复动作，非馆藏扫描。它继续使用原生 WebGL 组件的绘制与生命周期能力。旧茶器通过 `?id=tea-set` 保留为明确的次级示例，其来源和许可沿用下文记录。首页及相关文化页改为主题故事入口，秋季页面不再挂通用茶器。新增瓜豆酱互动为本项目新编排，事实与出处复用统一文化库；新几何不是从茶器模型修改而来。下文资产数值均指原茶器。

## 2. Heritage Foundry 实际复用了什么

本次检查的原仓库提交为 `ff4d18fa98a5dee96a09676939ed05e7e7af5220`。原资产及代码参考入口：

- [茶器原始 GLB](https://github.com/tbszz/Heritage-Foundry/blob/ff4d18fa98a5dee96a09676939ed05e7e7af5220/public/models/teapot.glb)：本次真实复用的网格、法线、UV 与贴图来源。
- [ArtifactStage.js](https://github.com/tbszz/Heritage-Foundry/blob/ff4d18fa98a5dee96a09676939ed05e7e7af5220/src/components/ArtifactStage.js)：展示居中、统一尺度、灯光、旋转、缩放和可见性生命周期的参考。
- [原始许可证](https://github.com/tbszz/Heritage-Foundry/blob/ff4d18fa98a5dee96a09676939ed05e7e7af5220/LICENSE)：代码与模型附注一并保留。

瓜游记没有直接运行原项目的浏览器 Three.js 舞台，也没有移入其文创生成后端。原页面的 DOM、OrbitControls 和浏览器渲染依赖不适合直接放入原生小程序，因此此次新增一个 WebGL 组件，通过小程序 Canvas 进行真实三角面绘制。

当前入口为 `pages/heritage/index`，页面名称为“风物展台”，展品名为“一席茶器”。用户可以拖动旋转、双指缩放、使用缩放按钮、暂停自动转动和复位。页面隐藏或销毁时停止动画，销毁时释放显存资源。数字展品与乡味手作情景建立导航联系，但**不把这套茶器归属为中牟实物、指定年代古物或经鉴定的非遗代表作**。

## 3. 资产转换与可复查证据

资产处理是文件格式和渲染适配，没有训练模型，也没有通过图片生成工具重新生成茶器。

| 项目 | 已核验结果 |
|---|---|
| 原始 GLB 大小 | 217,704 字节 |
| 原始 SHA-256 | `53f3f6d6c2fdf72bf216a7f1c8a47c7506b44973a44c506602913c1459c4336d` |
| 顶点数 | 5,356 |
| 三角面数 | 4,707 |
| 转换后的网格文件 | `miniprogram/assets/heritage/tea-set.bin`，199,650 字节 |
| 转换后的纹理文件 | `miniprogram/assets/heritage/tea-set.jpg`，131,375 字节 |
| 网格与纹理合计 | 331,025 字节；不含小体积元数据、许可文本和渲染代码 |
| 几何处理 | 保留索引拓扑、法线与 UV；居中并按最长边 2.35 等比缩放 |
| 纹理处理 | 原 WebP 纹理转为 JPEG，并控制纹理尺寸 |
| 运行时依赖 | 小程序原生 WebGL；没有 Three.js 或 Draco 运行时依赖 |

原 GLB 使用 Draco 压缩。为避免小程序运行时加载解码器，构建脚本先离线解压，再写出带文件头的轻量网格格式；运行时验证文件头、顶点数、字节长度和索引范围后再上传 GPU。三个坐标方向都具有非零尺寸，渲染采用 `drawElements(TRIANGLES, …)`；因此这里展示的是可改变观察角度的真实三维网格。

资产准备脚本为 `scripts/prepare-heritage.cjs`，元数据在 `miniprogram/assets/heritage/tea-set.metadata.json`。脚本对原始文件 SHA-256 作严格校验，下载内容发生变化时不会悄悄接受另一份资产。

从项目根目录复建的示例命令：

```sh
mkdir -p /tmp/guayouji-3d-tools
npm install --prefix /tmp/guayouji-3d-tools @gltf-transform/core@4.4.1 @gltf-transform/extensions@4.4.1 draco3dgltf@1.5.7 sharp
curl -L --fail https://media.githubusercontent.com/media/tbszz/Heritage-Foundry/ff4d18fa98a5dee96a09676939ed05e7e7af5220/public/models/teapot.glb -o /tmp/guayouji-3d-tools/teapot.glb
node scripts/prepare-heritage.cjs /tmp/guayouji-3d-tools/teapot.glb
node --test tests/heritage.test.js
```

这些 npm 包只用于构建，安装目录在 `/tmp`。正常导入已经生成资源的小程序开发版，不需要执行资产转换或安装上述包。需要更换构建工具目录时，可设置 `HERITAGE_TOOLS_DIR`。

## 4. 代码许可、资产许可与参赛用途

Heritage Foundry 的 MIT 代码许可与其模型使用附注需要同时阅读。此次完整保留 `miniprogram/assets/heritage/Heritage-Foundry-LICENSE.txt`，并增加 `miniprogram/assets/heritage/SOURCES.md` 记录下载来源、转换方式和用途。模型附注限定参赛演示等非商业场景，因此当前使用范围是瓜游记参赛开发版；本文不将其解释为模型可无限制商用。[依据：原项目 LICENSE](https://github.com/tbszz/Heritage-Foundry/blob/ff4d18fa98a5dee96a09676939ed05e7e7af5220/LICENSE)。

当前器物页明确标注其为来自原项目的数字展品与创意示意。旧项目的文化文案没有被直接搬入瓜游记的核验知识库，茶器资产也不构成历史、地域或非遗级别的证据。

如将来加入更多展品，应逐件记录来源、原始哈希、权利说明和转换版本；有地方馆藏或传承人提供的资产时，再依据实际授权标注归属。文物测绘、历史复原、传承人认证等表述，需要相应依据，不能由模型外观推断。
