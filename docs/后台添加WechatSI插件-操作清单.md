## 零、先说清楚为什么需要你动手

这个小程序的「语音输入」功能（用户在搜索框点麦克风、说话、自动转成文字）依赖**微信官方插件「微信同声传译」**。

## 三、详细步骤

### 第 1 步：登录并选中这个小程序

1. 电脑上打开浏览器，访问 **https://mp.weixin.qq.com/**
2. 点「**扫码登录**」，用**你名下注册了这个小程序的微信号**扫码
   - 注意：不是我的号，也不是你名下别的号
3. 如果登录后弹出「**选择账号登录**」，列表里挑**小程序**那一类下面的正确那个

**怎么确认选对了？** 登录进去之后：

- 左上角或右上角会显示小程序名称，`瓜游记` 或 `果物四时记` 都对（两个名字指的是同一个）
- 想更确定：左侧「设置」→「基本设置」，页面上「**小程序 AppID**」必须显示 `wx168d052d2db78132`

**如果 AppID 不是这一串**，说明选错号了，退出重选，**不要在那个号里做任何操作**。

### 第 2 步：添加插件

**直接走微信服务市场这条路**（后台自带的搜索框搜不出来，原因见下方）

1. 浏览器打开这个地址：

   ```
   https://fuwu.weixin.qq.com/service/detail/0000c6950745e87d6c5a143845c815
   ```

   这是微信官方服务市场里「微信同声传译」的服务页。页面上应该能看到：
   - 标题「**微信同声传译**」
   - 服务商「**深圳市腾讯计算机系统有限公司**」← 认这个，说明是官方那个
   - 一个「**添加插件**」按钮

2. 点「**添加插件**」
3. 按提示扫码登录（用**你名下注册了这个小程序的微信号**），然后在小程序列表里**选中 `瓜游记`**（显示 `果物四时记` 也是同一个）
4. 确认 → 回到小程序后台的「**插件管理**」，插件就已经躺在列表里了

> 也可以从服务市场首页 `fuwu.weixin.qq.com` 搜「**同声传译**」进同一个页面。
> 搜的时候**用全称，别用缩写**——市场里有名字相近的第三方插件，用全称才准确定位到官方那个。

#### 为什么不用后台自带的搜索框

后台那条路径是：左侧「设置」→「第三方设置」→「插件管理」→「添加插件」。
官方文档写的是「**通过 appid 查找插件并添加**」，但**实测这个搜索框搜 AppID 和搜中文名都返回「没有符合条件的搜索结果，请重新搜索」**——这是后台的已知毛病，**不是你的操作问题**，也不用去改小程序类目。

想自己验证是插件的问题还是账号的问题，可以在那个搜索框里随便搜个**别的**知名插件（比如「**腾讯位置服务**」）：

| 结果 | 说明 | 下一步 |
|---|---|---|
| 别的插件**能**搜出来 | 后台搜索是好的，只是「微信同声传译」这个条目有问题 | 用上面的**服务市场链接** |
| 别的插件**也**搜不出来 | 问题在**账号**（主体信息没完善 / 未认证 / 权限不足），跟插件无关 | 把截图发我，我判断该补什么 |

### 第 3 步：把版本号发我

添加成功后，在「插件管理」列表里找到「微信同声传译」，它旁边（或点开详情）会显示一个**版本号**，形如 `0.3.5`。

## 六、为什么顺序不能反（技术背景，可以跳过）

正确顺序是：**先在后台加插件 → 再上传代码**。

反过来的话，上传代码时微信会校验失败，报错码 `80082`（插件未授权）。

我们上次就是踩了这个坑：为了绕过 80082，把代码里的插件声明临时摘掉了，结果小程序上线后「语音输入」**静默失效**——点麦克风没反应，也不报错，界面只显示「暂不可用」。查了半天才定位到是这一层配置。

所以现在代码里的声明已经恢复了，**必须先加插件**，否则 80082 会再来一次。

## 七、加完之后我这边做什么（已完成 2026-09-28）

1. ✅ 跑项目静态检查（插件声明双向一致性 + 语音接口接线，就是防这次这种坑）
2. ⏳ **真机**验证语音输入 —— 微信开发者工具不支持录音，必须在真机上测
3. 验收四条：
   - 点麦克风 → 弹出权限授权 → 说一句话 → 文字回填到搜索框
   - 故意拒绝权限 → 提示「录音权限未开启，请在设置中允许」
   - 连续快速点两次 → 提示「正在识别中，请稍候」，不崩
   - 断网点一次 → 提示网络错误，不是空白
4. ⏳ 额外验收两条（双引擎特有）：
   - 真机上确认插件**流式**回填（边说边出字）正常，而不是等录完才出字
   - 临时把插件声明摘掉后，语音应**自动切到服务端**并仍能识别（验证兜底不是纸面上的）

## 八、备选方案 —— **已实装为兜底链路**（不再是「万一」）

原计划：万一插件加不上，改走**服务端识别**：

```
小程序录音 → 上传音频 → 服务端调用语音识别接口 → 返回文字
```

**这条路现在已经实现好了**，而且不是备胎——它与插件组成**双引擎**：插件能用就用插件（流式、免费），
插件不在或启动失败就自动切到服务端，`voice.engine` 会告诉你实际走的哪条。

- 优点：**不用插件、不用后台授权**，没有 80082 这类坑
- 优点：服务端识别支持方言（`zh` 含川/闽南/吴、`yue`、`en`），跟「四时乡野」的调性反而更搭
- 代价：会消耗 DashScope 额度；没有流式中间结果（界面用「正在识别…」补反馈）
- 代价：需先完成云端配对

所以**最坏情况下也只需要把 `app.json` 里的 `plugins` 声明删掉**，功能不会消失，只是降级。

细节见 `docs/提审清单-0.7.6.md` §四。
