**算法挑战赛道**（`第八届AIC算法大赛算法挑战赛道比赛流程.pdf`，逐字引用）：

> 一、报名阶段：参赛者在比赛官方网站上完成报名注册，提交个人或团队信息，**获取初赛数据下载链接**。
>
> 二、初赛阶段：参赛者**依托赛事方提供的训练数据集**开展算法模型设计，利用**提供的初赛测试集**进行相应方法的验证与调试。本阶段参赛者每日提交结果的次数不设限制，**初赛排行榜每 1 小时刷新一次**。
>
> ……若参赛者提交的算法性能**低于赛事方提供的基线参考分数**，将判定为无效成绩，不予授奖。
>
> 五、总决赛阶段：……提交完善后的技术文档、**算法代码和模型文件**、作品海报、答辩 PPT、补充材料等……
> **总决赛最终成绩 =（70% 排行榜得分 + 30% 答辩得分）**

**智能文化（算法主题赛）**（`附件1-竞赛规则及作品提交要求.pdf`，逐字引用）：

> 一、比赛赛制：主题赛采用"初赛-复赛-总决赛"三级赛制，**不分赛区，所有参赛作品统一评审**。

> 三、作品材料规范：作品材料包括：**作品名称、作品简介、技术方案、演示视频、答辩 PPT、佐证材料、作品其他材料链接**等。

**两边的差别是结构性的**：一边是「给你数据 → 你刷分 → 交代码复现 → 70% 看榜」；另一边是「不给数据 → 你自己选题 → 交技术报告 → 100% 专家评审」。

## 四、这对我们的项目意味着什么（5 条直接影响）

### 1. 「找不到数据集」这件事，到此为止

不用再找了。**智能文化赛道从第七届到第八届都不提供数据集**，这是设计而非缺失。第七届 35 支国赛获奖队伍，用的数据全是自己找的。

### 2. 我们最大的优势正好压在评分表上

`附件1` 「二、作品要求」第（三）条原文：

> **实用性与成熟度**：作品须具备实际应用价值，**已在实际场景中应用并取得良好效果，展示清晰的应用案例和数据证明**，或者应具备向实际应用转化的潜力和可行性方案。

对照评分表：**「应用成效 15 分」**（成果显著，效益突出，**数据详实**，得 10-15 分）。

**在一个人人都没有官方数据集、数据全靠自找的赛道里，「有真实上线的小程序 + 真实用户」是稀缺品。** 这不是锦上添花，这是这个赛道最主要的区分度来源之一。

### 3. 「佐证材料」这一栏别人填不满，我们能填

`附件1` 明确列出的佐证材料清单：**专利证书、软件著作权证书、论文录用/发表证明（首页）、企业合作意向书、用户反馈、试点应用证明**，合并为一个 PDF。

- **用户反馈** ← 我们有真实用户
- **试点应用证明** ← 如果我们能拿到果农/合作社或学校的落地证明，这一项直接落地
- 软著：小程序**可以申请软件著作权**，周期约 1-3 个月，现在动手还来得及

> 🎯 **行动项**：把「佐证材料」当成一个独立的得分项来准备，而不是最后顺手拼一下。这一栏是主题赛里少见的「纯靠整理就能拿分」的地方。

### 4. 「附录 1 数据资料」这条要求，反而是我们的加分位

`附件2` 附录第 1 条要求：**「提供实施过程中涉及的原始数据、处理后的数据及数据来源说明。」**

别人没有数据，我们有——而且我们的数据是**有源证据链**：每个文化事实都带 `sourceIds`，指向可核查的出版方与链接（`miniprogram/data/catalog.js` 里的 `sources` / `facts` 结构）。

**这条要求的字面意思就是「数据来源说明」，我们天生满足。** 应该把证据链整理成一份规范的《数据说明》放进附录，而不是让它散在代码里。

### 5. 「自训模型」的问题依然存在，而且更棘手了

`附件2` 附录第 2 条仍然要求：**「附上关键算法代码、模型文件及相关说明文档。」**

但主题赛**不给数据集**——所以自训练模型的训练数据**必须自己造**。

好消息是：`docs/辅助果农-可训模型清单-2026-09-27.md` 已经论证过，**「果实成熟度/商品等级分级」和「台账异常检测」这两个模型的数据可以自己造、不需要标注**。这条路在「没有官方数据集」的前提下，依然走得通。

> 这也是为什么给刘老师那封信里的第 2 个问题必须问清楚：**「核心调 API + 局部自训小模型」评审认不认。** 如果认，我们的投入方向就明确了。

## 五、一个反直觉的结论

**「没有数据集」对我们是好事，不是坏事。**

| | 如果有数据集（像挑战赛道） | 实际没有（主题赛） |
|---|---|---|
| 竞争维度 | 谁的分高 → 拼算力、拼调参 | 谁的问题好、谁落地了 → **拼选题与真实数据** |
| 我们的胜算 | 中（算力不是强项） | **高**（真实用户 + 有源证据链是稀缺品） |
| 需要的能力 | 模型能力 | 叙事能力 + 工程完成度 |

我们的强项（**完成度、真实用户、可运行 Demo**）恰好是主题赛最吃的东西。**之前担心的「只调 API 没有技术含量」，在这个赛道里的相对劣势，比在挑战赛道里小得多**——因为同赛道的对手也没有数据集、也多半在调 API。

> 但注意：这不等于「不用做自训模型」。评分表里「AI 技术应用 20 分」的**最高档明确要求「技术实现难度高且效果好」**，「创新性 25 分」的最高档要求「全新的 AI 应用模式」。**调 API 拿不到这两档的高分**——这一点判断没有变。
