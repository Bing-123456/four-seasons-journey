# 世界风物内容说明（可扩展性展示层）

登记日期：2026-09-22。世界风物是独立的微信分包 `packageWorld`（主包外，独立 2MB 预算），定位是**平台可扩展性的展示层**，不是产品重心：比赛评审的主叙事仍以河南示范区域的深度为准。

## 为什么有这一层

第八届 AIC 智能文化主题赛为开放式赛题，范围是"文化领域"，不要求世界化；通知背景提到"跨文化传播壁垒"。瓜游记的架构天然支持从"一省深度示范"扩展到"全球农业文化遗产网络"——分包即证明：新增区域内容包不动主包、不占主包预算、不影响既有行程与文化数据结构。

## 内容与来源

六站均来自联合国粮农组织"全球重要农业文化遗产"（GIAHS）体系及相关公开资料，横跨亚洲（中国红河哈尼梯田、菲律宾伊富高梯田、日本佐渡里山）、南美洲（智利奇洛埃土豆农业）、非洲（摩洛哥阿特拉斯绿洲）、欧洲（葡萄牙巴罗舒农牧系统）。

- 事实均引用 FAO GIAHS 官网与英文维基百科条目（链接随条目可复制核对）。
- 照片全部来自 Wikimedia Commons 开放许可（CC BY / CC BY-SA，署名与许可链接随卡片展示）。
- 双语标题（中文 + 英文名）回应"面向全球"的展示需求。

## 边界

世界层只做有源文化阅读，不提供行程规划、预约或任何到访安排；可规划的参考行程仍以河南示范区域为准。世界站点不进入行程算法、果农批次或游客信号统计。
