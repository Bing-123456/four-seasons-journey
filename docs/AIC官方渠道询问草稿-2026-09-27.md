## 一、为什么官方渠道应该和参赛者邮件同时发，甚至更早

| | 官方渠道 | 参赛者邮件 |
|---|---|---|
| **能回答什么** | **规则口径**（评分项、附录要求、材料规范） | **经验**（怎么做、怎么踩坑、答辩感受） |
| **答案效力** | 权威，可直接作为决策依据 | 个人经验，可能过时或片面 |
| **回复率** | 官方联系人职责所在，赛期内通常会回 | 学生，回不回看心情 |
| **我们最需要问的** | 附录 5 分附加分 / 自训模型口径 / 作品形态偏好 | 技术细节 / 备赛方法 |

**结论**：我们项目最关键的三个不确定性（是否保留附录附加分、自训模型是不是硬要求、赛道偏好生成还是检索），**参赛者答不了，只有官方能给准话**。这两封应该和批次 A 一起发。
