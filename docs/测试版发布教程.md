# 测试版发布教程（长期有效的体验版）

> 两种“测试版”的区别：
>
> | | 预览码（开发者工具生成） | 体验版（微信后台设置） |
> |---|---|---|
> | 有效期 | **约 25 分钟** | **永久有效**，直到被替换 |
> | 谁能用 | 仅扫码的开发者本人 | 所有添加进“体验成员”的微信号 |
> | 生成方式 | 开发者工具 / 命令行 | 微信公众平台网页后台 |
>
> 给团队成员长期测试，一定用**体验版**。

---

## 第一步：上传代码（命令行一条命令，或开发者工具点按钮）

在项目根目录执行：

```bash
/Applications/wechatwebdevtools.app/Contents/MacOS/cli upload \
  --project "/Users/mychanging/Desktop/人工智能大赛比赛项目" \
  --version "0.3.14" \
  --desc "测试版说明写这里"
```

- `--version`：版本号，每次发版递增（0.3.14 → 0.3.15 …）
- 上传成功后，代码会出现在微信后台的「开发版本」里
- （本项目也可直接用 `npm run package` 打交付 zip，但上传这步必须做）

## 第二步：设为体验版（网页后台操作，一次性 2 分钟）

1. 浏览器打开 **[mp.weixin.qq.com](https://mp.weixin.qq.com)**，用本小程序的管理员微信扫码登录
2. 左侧菜单 → **管理 → 版本管理**
3. 页面下半部分找到 **「开发版本」** 列表，最新上传的 `0.3.14` 就在里面
4. 点该条目右侧的 **「选为体验版」** 按钮
5. 弹窗里可以填写“体验版路径”，留空直接确定
6. 设置完成后，页面顶部 **「体验版」** 卡片会出现二维码——**这就是长期有效的测试版二维码**，下载后发给团队即可

## 第三步：添加体验成员（没加的人扫码会提示无权限）

1. 左侧菜单 → **管理 → 成员管理 → 体验成员**，点 **「添加」**
2. 输入队员的微信号，确认（队员微信里会收到邀请，需点同意）
3. 体验成员上限 15 人；用完名额先移除旧成员

## 第四步（每次发新版后）：更新体验版

- 再次 `upload` 后，新代码只出现在「开发版本」
- 需要**重新到版本管理页，把最新条目重新“选为体验版”**，体验版二维码不变，但内容会指向新代码
- 体验成员无需重新添加

## 常见问题

| 问题 | 处理 |
|---|---|
| 扫体验版码提示“未加入体验成员” | 在成员管理把该微信号加进体验成员，并让对方在微信里同意邀请 |
| 后台看不到刚上传的版本 | 确认上传命令里的 AppID 是 `wx168d052d2db78132`，且登录后台的是同一主体 |
| 想收回某个版本 | 版本管理 → 体验版 → 回退；或直接把新版本再设为体验版覆盖 |
| 预览码过期 | 用命令行重新生成即可（仅自己调试用） |

## 本项目快捷发版流程（已验证）

```bash
# 1. 改 miniprogram/app.js 里的版本号
# 2. 跑测试 + 打包 + 上传 + 生成预览码
npm test && npm run package
/Applications/wechatwebdevtools.app/Contents/MacOS/cli upload \
  --project "$PWD" --version "0.3.x" --desc "版本说明"
# 3. 网页后台「选为体验版」（见第二步）
```
