# 0.3.6 修复与验收（2026-09-25）

本轮针对 AI、识果、两类图片生成的实际故障展开修复，同时优化主要界面，并首次部署到用户指定的 VPS `60.204.231.189`。

## 已修复

| 问题 | 修复 |
|---|---|
| 图片页面将字符串会话令牌当作对象，始终判为未配对 | 统一图片请求入口，正确携带令牌，401 提示重新配对并清除对应过期会话 |
| 正常识果照片超过全局 16KB 限制 | 图片独立 3MiB 请求体，解码图片限制 2MiB，核验文件签名 |
| 识果绑定了文字模型开关、无视觉配置仍发纯文本 | 独立视觉配置和健康状态，禁止无图识别 |
| 国风生图传 keyword，供应商 adapter 读取 prompt | 统一 prompt 契约，真实异步生图与完成结果缓存 |
| 照片转伙伴使用不匹配的图像编辑功能 | 使用供应商 description_edit，将真实照片转为卡通伙伴 |
| PNG 被硬标 JPG、大图被截断、窄图尺寸不合要求 | 根据签名选择类型，压缩超大图、规范图生图尺寸，拒绝损坏输入 |
| 伙伴生成后保存值为数字、缺描画字段、目录不存在 | 保存真实分区文件路径，更新编辑器和画布，完整保留可编辑配置 |
| 本地照片保存后再点保存会回到旧模板 | 同步照片到编辑器，支持照片预览与编辑，文件按账户分区清理 |
| 图片查询一次网络波动就永久失败 | 保留原任务并有限重试，账户/地址变更时停止继续访问 |
| 多用户共用单一配额、轮询耗尽提交配额 | 鉴权后按会话分配配额，图片轮询采用独立限制 |
| 翻译任务存在但无 HTTP 路由，长输出被截断 | 注册翻译路由，调整翻译/故事/卖家输出额度 |
| 天气缺数据却显示晴、0℃，同城换批次复用错误雨天数 | 不完整数据明确显示未知，缓存原始预报并按批次窗口重算 |
| 欢迎页仅显示挥手线条、画布导出兼容性差 | 优先用微信画布导出 API，普通图片展示，过滤过期导出结果 |

## 界面

统一奶油白、松绿、陶土色和按钮、卡片、字体层级；优化发现、我的、卖家、搜索、文化活动、伙伴、四时、文化详情和游戏页。修复农场日历被挤窄、卖家信号卡错误横排、搜索和昵称输入溢出、农户入口被底栏遮挡。

小游戏顶部加入内置 image_gen 生成的原创插画，素材与完整提示词见[界面插画说明](界面插画说明.md)。真实地点照片仍保留原有来源。

## 部署与使用

API：`https://demo.orionsheep.com/guayouji`。

最终发布编号：`20260925T015836Z-58292`。独立 systemd 服务 `guayouji.service`，仅在回环地址监听，由现有 HTTPS 域名的专用路径反代；匿名调用业务接口返回 401。原有站点保持正常。

「我的 → 开发体验服务 → 使用线上服务 → 检查连接」，输入服务器当前开发配对码。文字 AI 需要主动打开开关；图片功能独立于文字开关。服务重启或短期会话过期需要重新配对。如何读取配对码、再次同步和回滚见[VPS 部署](VPS部署.md)。

源码同步到 VPS 不等同于微信小程序上传/发布。手机正式运行仍需配置请求域名、供应商下载域名及微信平台权限；本轮没有提交微信审核或替用户发布体验版，也没有宣称完成真机权限验收。
