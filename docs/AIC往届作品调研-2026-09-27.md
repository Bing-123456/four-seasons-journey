## 三、关键纠正：「智能文化」不是新赛道

之前我基于第八届通知的措辞，误判「智能文化」为第八届新设赛道。**这个判断是错的**。

证据链：

1. 第八届通知原文：「自2019年起已经连续举办七届」——只说明赛事历史，未说赛道是新的。
2. 第七届赛道页 <https://www.aicomp.cn/tracks/1805.html>（2025-07-27 发布）标题即「AIC·"智能文化"算法主题赛赛题及竞赛规则」，正文明确写：**「赛题说明（赛题代码 AIC-TC-002）」**。
3. 第七届国赛获奖名单 PDF 标题为「算法主题赛（AIC-TC-001至012）全国总决赛获奖名单」，其中 `AIC-TC-002 智能文化` 共 35 项获奖。

**第八届的措辞之所以像「新赛道」**，是因为第八届把「智能文化」单独发了一份通知（全智赛组委会〔2026〕24号），并改为**北京邮电大学承办**、配了全新的附件。这是**升级/独立化**，不是新设。

**对备赛的实际意义**：往届的赛道规则、评分偏好、获奖作品方向**全部适用**，而且第八届的评分表与第七届**几乎一字未改**（详见第六节）。

## 八、对当前项目的可借鉴点

### 8.1 三条可直接执行的

1. **下载第八届《作品方案模板》**（网盘链接见上），第八届是「填模板」而非自由发挥。**没下载模板 = 形式审查风险。**
2. **在赛题 QQ 群（145274278）确认附录附加分是否仍在**，以及「AI 技术工具选择与运用」章节里**自训练模型 vs 调用 API 的评审口径**。
3. **精读 `TianYi-1412/library-recommendation-competition` 的 `docs/` 目录**——它是同赛事里文档最完整的中文开源仓库，技术报告的组织方式（算法家族对比 → 版本演进 → 实验结果 → 关键技术总结）可以直接套用到我们的技术报告结构上。

### 8.2 两条战略判断

4. **「小切口非遗/地域文化 + 技术」是被验证能进国赛二等奖的路线**。「石犬衍新」用雷州石狗（一个地方性图腾）就拿到全国二等奖。我们的**二十四节气 + 物候 + 农谚 + 地域果物**是同一量级甚至更厚的文化资产——**关键是把它讲成「文化传承创新」，而不是「水果百科工具」**。

5. **开源是差异化加分项**。该赛道 GitHub 命中 0 个仓库，说明绝大多数参赛者不开源。而「应用成效（15 分）」和「佐证材料」都吃「社会影响 / 用户反馈」。**我们已开源的代码 + 真实用户数据 + 可访问 Demo，是往届该赛道参赛者普遍没有的东西**——这应该被明确写进技术报告的「应用成效」章节，而不是藏在附录里。

### 8.3 一个需要警惕的点

6. **不要把「调用大模型 API」包装成「自研模型」**。第八届大纲附录明确要求「模型文件及相关说明文档」，评委大概率会核验。往届「石犬衍新」自述「多轮模型训练与调试」——**二等奖以上的作品是有训练环节的**。这正是 `技术挖掘与冲奖方案-2026-09-26.md` 里「引用支持验证器」方向的价值所在：它让我们**真的有一个自训练的小模型**，且与已有的重排器规划同源标注、一次投入两个模型。
