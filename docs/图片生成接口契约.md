# 水果伙伴图片接口 · 开发版预留

版本：0.2.0，2026-09-22。本轮未配置生图提供商，不调用阿里、DeepSeek 图片或本机模型。文字模型仍独立使用原有官方 DeepSeek。配置文字模型不等于开启图片服务。

| 接口 | 输入 | 响应与边界 |
| --- | --- | --- |
| GET /health | 无 | 新增 image：configured、availability、uploadEnabled、maxImageBytes、styles。生产入口始终 disabled。 |
| POST /api/companion/uploads | JSON `{confirmed:true,mimeType,base64}` | 已配置适配器时返回 202 `{resourceId,expiresAt}`；上限 2MB，校验格式和签名。未配置先返回 503 `image_provider_disabled`，不解码、保存图片。 |
| POST /api/companion/generations | `{resourceId,style:"fruit-line-art",requestId}` | 202 `{taskId,status}`；请求标识幂等，同一标识换资源拒绝。 |
| GET /api/companion/generations/:id | 与创建时相同的开发会话 | queued / generating / succeeded / failed。成功含 HTTPS imageUrl 和 AI创作插画 标识。过期、另一会话均 404。 |

只允许从 createServer 的测试构造参数注入 imageAdapter。适配器实现 upload({bytes,mimeType})、create({resource,style,requestId})、status(providerId)。生产 server/index.js 不注入，不包含假生成器。测试仅使用内存夹具，无对外请求。记录 TTL 30 分钟，最多100个暂存资源与任务，重启失效；此约束不代表将来的正式存储设计。

客户端 `companion-api.createClient` 默认 disabled；测试可显式注入 transport。确认前、未配置、演示模式均不上传、不创建任务。离页 clear() 使迟到回调失效；切换演示使状态回到 disabled。照片编辑页本轮只使用 chooseMedia 本机预览，没有调用上述上传接口。

后续真实服务接入仍需：配置独立密钥与区域域名、前端明确上传确认、资源持久化与删除策略、正式微信用户鉴权、配额与费用上限、图片内容审核、供应商超时恢复。供应商临时结果应先下载到受控存储，用户确认后再作为伙伴。不得把开发配对会话当成正式多用户身份。
