## 一、硬约束（改代码前先看）

- **改完必须跑** `npm run check` + `npm test`。
- **主包硬上限 2 MiB**，当前 **2,029,877 B**（余量约 **65 KB**）。
- **禁本地 `.webp`**（iOS 不渲染）；本地位图只用 jpg/png。
- **WXML 表达式不执行数组/字符串方法**（`indexOf` 恒为假 → `wx:if` 永不成立）。布尔/切片/拼接都在 JS 里算好。
- 实拍图必须有署名 + 许可 + 打包进包。
- 作品材料**不得出现学校名称、LOGO、指导教师信息**（赛事红线）。

## 二、check 拦的是同一类事故：check 全绿、线上静默降级

| 规则 | 拦的是什么 |
|---|---|
| **插件双向一致** | ① 代码用到插件 ⟹ 必须有 `plugins.X`；② 声明了 ⟹ 必须有人用（**没人用的声明照样要授权、照样撞 80082**） |
| 插件名支持**常量间接引用** | `requirePlugin(PLUGIN_NAME)` 要能解析；**解析不出来直接报错**——假装在工作的检查比没有检查更危险 |
| `speech-input.js` 里的 `/api/*` 必须在 `server/app.js` 有路由 | 路由漏写不会让 check 变红，只会让用户点麦克风时静默降级 |
| 评测集 `placeId` / `relevantFactIds` 必须存在于 catalog | 见第四节 |
| 密钥扫描（`sk-...`） | 代码与 docs 均扫描 |

**原则**：任何「静默降级」路径都要配一条静态检查。对用户友好 ≠ 对工程友好。

## 四、评测数据引用错位：会静默污染实验结论

**事故（2026-09-28 修复）**：评测集 `culture-seed.json` 里 q004/q019/q026 的 `placeId` 写成 `autumn-field`，而 catalog 里根本没这个地点（正确是 `autumn-orchard`）。系统返回「没有找到这个文化条目，请重新选择」——**一条给用户的报错文案被当成模型拒答计入了指标**，误拒率从 0.071 抬到 0.143。

- 评测集引用的 `placeId` / `relevantFactIds` 必须真实存在于 catalog → 已加进 `npm run check`。
- **指标异常时，先查数据引用，再查模型。**
- 数据集变更要**升版本号**并在 `labelStatus` 写明改了什么（当前 `culture-seed-2026-09-28-v2`）。

## 五、工具环境坑

- **本机 shell 的 `grep` / `ls` 不可靠**（有匹配却返回空、漏文件）→ **凡「搜不到 / 找不到」的结论，一律用 Grep / Glob 复核后再下判断。**
- **Grep 默认跳过隐藏目录**（`.workbuddy-ai/`）→ 搜记忆/配置目录要**显式传 path**。
- **同一文件禁止并行 Edit**：后发的基于旧快照写回，把前一次改动**静默吃掉**（仍返回 success）→ 同文件多处修改**必须串行**，改完 `node -e` 数关键字复核。
- **Bash 会误报退出码**（实际 exit=0，却返回 137/SIGTERM 且 stdout 空）→ **长脚本 `> file 2>&1` 落盘再 Read**。
