## 四、预览通道 41002：插件能上传、不能预览

**现象（2026-09-28）**：`cli upload` 成功，`cli preview` 稳定失败（3 次、不同 rid）：

```
provider:wx069ba97219f66d99, version:0.3.5, 系统错误，错误码：41002, appid missing
```

**已排除的原因**：
- 不是 `app.json` 声明问题（`plugins.WechatSI` 0.3.5 / provider 均正确）；
- 不是 IDE 缓存脏（`cli close` 重启后仍复现）；
- 不是 appid 缺失（CLI 明确打印 `Using AppID: wx168d052d2db78132`，`project.config.json` 也有）。

**推论**：`upload` 与 `preview` 的插件校验强度不同 —— upload 只校验「后台是否添加了插件」
（没加会报 **80082**），preview 还要向插件服务端换取插件包，此时 41002 说明**授权链没打通**。
→ 去 `mp.weixin.qq.com` → 设置 → 第三方设置 → **插件管理**，核实 WechatSI 是否为「已授权」
（而非「申请中」）。**本地无法绕过。**

**降级后果**：拿不到预览码 → 真机验证只能走「后台把开发版设为体验版」（需管理员权限）。

**踩坑提醒**：`cli preview` 的 `--qr-output` / `--info-output` **必须传绝对路径**，
传相对路径报「输出路径无效或不存在」——但这个报错会**盖住**真正的错误，
把路径改对之后才暴露出 41002。遇到 preview 失败先确认路径是绝对的。
